# 후속 버전 범위

다음 항목은 MVP에 포함하지 않는다. 실제 사용 중 필요성이 확인된 경우에만 검토한다.

- 연속 미응답 횟수를 이용한 상태 흔들림 방지
- 예약자와 예약 만료 시각
- 여러 CIDR 또는 VLAN별 Scanner
- 상태 변경 이력과 감사 로그
- 웹 기반 네트워크 설정
- 사용자 인증과 권한
- PostgreSQL, Redis 및 다중 인스턴스
- DHCP, Router/Switch 또는 SNMP 연동
- MAC Vendor 표시

후속 기능을 MVP에 포함하도록 변경할 때는 [00-product-scope.md](./00-product-scope.md)의 목표·비목표와 관련 영역 스펙을 함께 갱신한다.
