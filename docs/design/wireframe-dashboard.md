# 대시보드 와이어프레임 — 서브넷 맵

## 문서 정보

| 항목 | 내용 |

이 문서는 대시보드의 **화면 구조·영역·상호작용·상태 표현**을 정의한다. 색·타이포·컴포넌트 등 시각 규칙은 [design-system.md](./design-system.md)를 따른다. 화면에 표시하는 데이터의 정의와 상태 판정은 스펙 문서가 기준이며, 이 문서는 그 표현만 다룬다.

## 선택한 방향

3개 후보(서브넷 맵 / 데이터 테이블 / 운영 콘솔) 중 **서브넷 맵**을 채택한다.

- 대상 CIDR의 모든 IP(최대 254개)를 옥텟 그리드로 한 화면에 펼쳐, 비어 있는 IP(할당 후보)를 시각적으로 빠르게 찾는다. 이는 "새 디바이스에 사용할 IP 후보를 빠르게 찾게 한다"는 제품 목표에 가장 부합한다.
- IP 상세는 **우측에서 슬라이드로 열리는 드로어(오버레이)**로 표시한다. 드로어는 그리드 위에 겹쳐 열리므로 그리드는 항상 전체 폭을 유지하고, 닫으면 즉시 개요로 복귀한다.

인터랙티브 프로토타입(참고용, 비공개): https://claude.ai/code/artifact/2799e635-f3ab-43e1-97ce-82d6806649e3

## ① 상태 스트립

한 줄로 스캔 컨텍스트를 제공한다. 표시 항목은 [04-web-and-realtime](../spec/04-web-and-realtime.md)의 대시보드 요구사항을 따른다.

| 요소 | 내용 | 비고 |
| --- | --- | --- |
| 대상 CIDR | 예: `172.16.3.0/24` | 읽기 전용. 웹에서 변경하지 않는다 |
| 인터페이스 | 예: `eth0` | 읽기 전용 |
| 마지막 정상 스캔 | 로컬 시간 표기 | 저장은 UTC, 화면에서 변환 |
| 스캔 상태 배지 | `정상` / `스캔 중` / `스캔 오류` 중 하나 | 아래 상태 규칙 참고 |
| 지금 스캔 | 즉시 스캔 요청 버튼 | `POST /api/scan` |

스캔 상태 배지:

- `정상`: 마지막 스캔이 성공했고 유휴 상태. 마지막 정상 스캔 시각을 함께 보인다.
- `스캔 중`: 스캔 진행 중. 완료되면 `정상`으로 돌아간다.
- `스캔 오류`: 아래 오류 배너를 함께 표시한다.

오류 배너(스캔 실패 시):

- 스트립 하단에 위험색 배너로 실패 사실과 원인 요약을 보인다.
- **기존 IP 상태를 변경하지 않으며, "모든 IP가 비어 있음"으로 표시하지 않는다**는 점을 문구로 드러낸다.
- 다음 정상 스캔이 성공하면 배너를 해제한다. (근거: [02-network-scanning](../spec/02-network-scanning.md) 스캔 실패, [04-web-and-realtime](../spec/04-web-and-realtime.md) `scan-error`)

## ② 통계 요약

카드 형태로 요약 수치를 개요 우선으로 보인다.

| 지표 | 정의 |
| --- | --- |
| 전체 | 대상 IP 총수(네트워크·브로드캐스트 제외, 최대 254) |
| ACTIVE | 사용 중 |
| INACTIVE | 과거 사용 |
| AVAILABLE | 미사용 추정 |
| 할당 후보 | 표시 상태 `effectiveStatus == AVAILABLE && !isReserved` (강조 표기). aging이 꺼져 있으면 `observed_status`와 같다 |
| 예약됨 | `isReserved == true` |

규칙(반드시 지킨다):

- `ACTIVE + INACTIVE + AVAILABLE == 전체`. 탐지 상태 수의 합은 전체 대상 IP 수와 같다. aging이 켜져 있으면 이 합은 **표시 상태** `effectiveStatus` 기준이다.
- 예약됨은 탐지 상태와 중복되는 **별도 지표**다(상태 카드 합계에 더하지 않는다).
- 할당 후보는 표시 상태가 `AVAILABLE`이면서 예약되지 않은 IP만 포함한다.

(근거: [03-state-and-storage](../spec/03-state-and-storage.md) 상태와 예약의 분리)

## ③ 툴바

검색과 필터는 **최대 254개를 브라우저에서** 처리한다. 별도 검색 API는 두지 않는다.

- **검색**: IP · MAC · 메모를 대상으로 부분 일치. 입력 즉시 그리드에 반영.
- **상태 필터**: `전체` · `사용 중` · `과거 사용` · `미사용 추정` · `할당 후보`. `할당 후보`는 `effectiveStatus == AVAILABLE && !isReserved` 계산 결과를 필터한다.
- **예약 필터**: `전체` · `예약만` · `미예약`.
- **범례**: 글리프↔상태 매핑과 예약 표기를 항상 노출해, 색에 의존하지 않고 의미를 읽게 한다.

검색·상태·예약 필터는 AND로 결합한다.

## ④ IP 그리드

대상 IP를 옥텟 오름차순으로 타일 그리드에 배치한다.

타일 구성 요소:

- 마지막 옥텟 숫자(예: `.42` → `42`)를 중앙에 표기(데이터 폰트, 고정폭 숫자).
- 좌상단에 **상태 글리프**(`●`/`◐`/`○`)를 얹는다.
- 상태에 따라 배경 tint를 적용한다.
- 예약된 IP는 **테두리(inset)와 자물쇠 글리프**로 표시한다. 예약은 탐지 상태와 독립적이므로 어떤 상태의 타일에도 함께 나타날 수 있다.
- 각 타일은 버튼이며 접근성 라벨에 `IP · 상태 · (예약)` 전체 정보를 담는다.

상태·예약·할당 후보의 정확한 글리프·라벨·색 매핑은 [design-system.md](./design-system.md)의 "상태 표현 규칙"을 단일 출처로 삼는다.

그리드는 열 수를 화면 폭에 맞춰 자동 조정한다(반응형). 색만으로 상태를 구분하지 않는다.

## ⑤ 상세 드로어

타일을 선택하면 우측에서 드로어가 슬라이드로 열린다(그리드 위 오버레이, 그리드 폭 불변).

표시 필드([04-web-and-realtime](../spec/04-web-and-realtime.md) IP 상세):

- IP 주소
- 현재 탐지 상태(글리프 + 라벨) — 표시 상태 `effectiveStatus`
- 예약 여부(배지)
- MAC 주소
- 최초 발견 시각
- 마지막 사용 확인 시각
- 마지막 검사 시각
- 작업 메모
- stale 항목이면 "과거 사용 이력" 안내(`observed_status`가 `INACTIVE`인데 표시는 `AVAILABLE`)

편집 동작:

- **메모**: 텍스트 편집 후 저장(최대 1,000자).
- **예약**: 예약/예약 해제 토글.
- 표시 상태가 `AVAILABLE`이면 "실제 미사용을 보장하지 않으며 고정 IP 할당 전 최종 확인이 필요하다"는 안내를 함께 보인다. (근거: [03-state-and-storage](../spec/03-state-and-storage.md))

닫기: 닫기 버튼 · 스크림(바깥 영역) 클릭 · `Esc` 키.

## 상호작용 흐름

| 트리거 | 동작 | 서버 요청 | 후속 |
| --- | --- | --- | --- |
| 타일 선택 | 드로어 열림 | 없음(메모리 데이터) | — |
| 검색·필터 변경 | 그리드 즉시 갱신 | 없음(브라우저 처리) | — |
| 메모 저장 | 메모 커밋 | `PATCH /api/ips/:ip` | 커밋 후 `dashboard.updated(note)` |
| 예약 토글 | 예약 변경 | `PATCH /api/ips/:ip` | 커밋 후 `dashboard.updated(reservation)` |
| 지금 스캔 | 스캔 상태 `스캔 중` | `POST /api/scan` | 완료 시 `dashboard.updated(scan)` |
| SSE 수신 | 화면 부분 갱신 | `GET /events` | 변경 IP만 갱신, 재연결 직후엔 `GET /api/dashboard`로 전체 스냅샷 재조회 |

메모·예약 변경은 일반 HTTP로 처리하고, 저장(커밋) 후에만 SSE로 다른 화면에 알린다. 스캔 실패 시에는 DB 변경 없이 `scan-error` 이벤트만 보낸다. (근거: [04-web-and-realtime](../spec/04-web-and-realtime.md))

## 화면 상태

| 상태 | 표현 |
| --- | --- |
| 최초 로딩 | 스트립·통계·그리드 골격을 먼저 보이고 데이터로 채운다 |
| 스캔 중 | 상태 배지 `스캔 중`. 기존 그리드는 그대로 유지 |
| 스캔 오류 | 오류 배너 표시, **기존 상태 유지**(빈 상태로 표시하지 않음) |
| 검색 결과 0건 | 그리드 영역에 "조건에 맞는 IP 없음"과 필터 초기화 안내 |
| 연결 끊김/재연결 | 자동 재연결 후 스냅샷 재조회로 동기화 |

## 반응형 동작

| 폭 | 그리드 | 드로어 | 통계 |
